# STAVBY PRO Release Manager 7.1.0 LTS – Build 254 DEV014

## Developer Center UX

- Jedno hlavné tlačidlo **ULOŽIŤ BUILD** nahrádza samostatné commit/tag akcie.
- Automatický prehľad projektu, vetvy, verzie, buildu, navrhovaného tagu a počtu zmien.
- Automatický návrh commit správy a tagu z `pubspec.yaml` a identity projektu.
- Predbežné kontroly vetvy `develop`, repozitára `origin`, zmien a kolízie tagu.
- Záverečný dialóg so stavom vetvy, commit hashom a tagom.
- Možnosť skopírovať hash úspešného commitu.
- Git operácie zostávajú v poradí: add → commit → tag → push vetvy → push tagu.
