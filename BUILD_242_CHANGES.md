## Plugin Configuration UI

- pridaný univerzálny dialóg konfigurácie pluginu,
- podpora textu, celých a desatinných čísel, boolean hodnôt, JSON zoznamov a objektov,
- načítanie, validácia a uloženie cez `PluginConfigurationManager`,
- obnovenie predvolených hodnôt,
- zobrazenie validačných chýb priamo v dialógu,
- voliteľné pripojenie konfiguračných schém k `PluginManagerPage`,
