# Build 256 DEV002 – Unified Release Wizard

- Release Wizard krok 4 bol zmenený z GitHub Release na **Dokončiť vydanie**.
- Krok otvára existujúci Build Completion Center priamo z Release Wizarda.
- Workflow hlavička teraz zobrazuje ZIP → Build → Export → Dokončiť vydanie → Test EXE.
- Samostatný GitHub modul zostáva dostupný ako sekundárna akcia pre pokročilé nastavenia a aktualizácie.
- Build Completion Center zostáva jediným miestom pre Commit Message, popis zmien, Commit, Push, Tag, ZIP, report a históriu.
