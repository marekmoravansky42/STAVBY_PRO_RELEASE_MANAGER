# DEV026 FIX003 – Release Wizard Quick Build

1. Otvor Release Wizard.
2. V kroku 1 klikni **QUICK BUILD: ZIP → BUILD**.
3. Vyber ZIP zdrojového projektu Release Managera.
4. Over, že ZIP sa rozbalí, projekt sa automaticky načíta a bez ďalšieho kliknutia sa spustí kompletný Windows build.
5. Over, že pôvodné tlačidlo **VYBRAŤ A ROZBALIŤ ZIP** stále iba rozbalí a načíta projekt.
6. Over, že v kroku Build Release Managera zostáva dostupný ručný výber projektu.
