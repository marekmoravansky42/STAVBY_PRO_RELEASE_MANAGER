# STAVBY PRO Release Manager 8.0.0 RC1 — Build 257

## Release Candidate 1

Build 257 RC1 je povýšený z úspešne otestovaného Build 256 DEV004 FIX002.

### Zahrnuté hlavné funkcie RC1

- Unified Release Wizard.
- Project Profiles s rýchlym prepínaním uložených projektov.
- Local Build Assistant napojený na existujúci One Click Build workflow.
- Workspace Manager a Workspace Health.
- Export / Import pracovného prostredia vo formáte `.rmworkspace`.
- Startup Wizard pre prvotné nastavenie.
- Windows, Android APK a Android AAB akcie v Development Center.
- Existujúca Git integrácia, Release ZIP a diagnostický workflow zostali zachované.

### Stav pred povýšením

Build 256 DEV004 FIX002 bol otestovaný cez Quick Build a aplikácia sa úspešne spustila. RC1 nemení build engine ani otestovanú funkcionalitu; aktualizuje release identitu a metadata pre Release Candidate.

### Nasledujúci krok

RC1 je určený na finálny integračný test pred uzavretím vetvy 8.0 RC1 a návratom k vývoju STAVBY PRO.
