# FIX009 – Live Build Progress

Implements the approved Image 1 concept directly in the real dashboard.
During FAST/FULL One Click Build, the Posledný build card now shows:
- active build indicator,
- percentage progress,
- live progress bar,
- current build step/status.

The progress is driven by the existing One Click Build state and disappears after the build finishes.
No new concept image is generated for this implementation.
