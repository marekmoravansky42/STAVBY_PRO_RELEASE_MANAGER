# DEV026 FIX005 – Workflow Status Indicators

## Test
1. Otvorte Release Wizard.
2. Kliknite **QUICK BUILD: ZIP → BUILD** a vyberte zdrojový ZIP.
3. Po dokončení rozbalenia sa indikátor kroku ZIP musí zastaviť.
4. Krok **Rozbaliť ZIP** musí dostať zelenú fajku a text **Dokončené**.
5. Počas Windows buildu sa už nesmie točiť indikátor na ZIP tlačidle.
6. Build musí pokračovať automaticky.
