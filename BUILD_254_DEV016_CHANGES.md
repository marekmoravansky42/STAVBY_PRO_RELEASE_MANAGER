# STAVBY PRO Release Manager 7.1.0 LTS – Build 254 DEV016

## Project Dashboard v1

- Úvodný Dashboard automaticky používa posledný uložený Git workspace.
- Zobrazuje názov projektu, úplnú cestu v tooltipe, verziu, build a vývojovú fázu.
- Zobrazuje aktívnu Git vetvu, stav pracovného stromu, posledný commit a posledný tag.
- Ak projekt nie je vybraný, ponúkne systémový výber pracovného projektu.
- Ak je projekt platný Git repozitár, sprístupní akciu „Pokračovať vo vývoji“.
- Pridané akcie Zmeniť projekt a Obnoviť stav.
- Responzívne rozloženie funguje na úzkych aj širokých oknách.
- Git Workspace Persistence a Git Build Publisher z DEV015 zostávajú zachované.
