# Release Manager 7.1.0 LTS – Build 254 DEV021

## Build Completion & Export Center

- One Click Build automaticky vytvorí Windows Export Release ZIP.
- ZIP sa uloží do nastaveného Windows Release exportného priečinka; ak nie je nastavený, použije sa `Export Release` vo workspace.
- Záverečné okno zobrazuje projekt, verziu, build a čas trvania.
- Priamo zo záverečného okna možno označiť ZIP v Prieskumníkovi, spustiť EXE, označiť report a uložiť build do Gitu.
- Export ZIP obsahuje kompletný obsah `build/windows/x64/runner/Release`.
