# Release Manager 7.1.0 LTS – Build 254 DEV026 FIX025

## Simple / Developer Mode

- Added a permanent mode switch at the top of the left navigation.
- Simple mode keeps only the daily workflow pages visible.
- Developer mode restores Analyzer, GitHub updates, plugins, remote agents and settings/help.
- When switching to Simple mode from a hidden advanced page, the app safely returns to Dashboard.
- Existing pages and functionality are not removed.
