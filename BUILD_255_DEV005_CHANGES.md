# BUILD 255 DEV005 – Completion Output Actions

## Zmeny

- Výsledkové okno Build Completion Center obsahuje pri dostupných výstupoch tlačidlo **BUILD REPORT**.
- Tlačidlo **RELEASE ZIP** otvorí Prieskumníka a označí vytvorený ZIP.
- Tlačidlo **GITHUB COMMIT** otvorí aktuálny commit na GitHube.
- Tlačidlá sa zobrazia iba vtedy, keď príslušný výstup alebo odkaz existuje.
- Chyba pri otvorení výstupu sa zobrazí ako používateľské hlásenie bez pádu aplikácie.
- Zachovaný je celý stabilný workflow z DEV004 FIX002.
