# FIX032 – Project Profiles Window

- Dashboard button `Zmeniť projekt` now opens a dedicated `Project Profiles` window.
- Shows all saved project profiles with path, Git branch, platforms and active state.
- One click switches the active project/workspace.
- `PRIDAŤ PROJEKT` creates a new saved Project Profile.
- Profile menu supports open, rename, duplicate and remove.
- Existing Project Profiles storage/service is reused; no duplicate profile system was introduced.
