# FIX075 – Release Compare v1

Built from confirmed FIX074.

Release History now allows selecting two releases and comparing them directly.

Comparison shows:
- release names;
- Release vs LTS / FINAL type;
- detected platforms;
- modification date/time;
- Windows presence;
- Android presence;
- Reports presence;
- direct open buttons for both release directories.

Selection is intentionally limited to two releases at a time.
